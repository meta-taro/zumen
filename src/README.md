# `src/` — 確定した形式の実装

ここに置くのは **`spec/zumen-format-v1.md` を実装したもの**だけ。

| ファイル | 中身 | 仕様の対応 |
|---|---|---|
| `format.ts` | 正本の読み書き。コメント・空行・並び順を壊さない | §3 / §6.1 |
| `merge.ts` | AI の提案を人の正本へ入れる。黙って上書きしない | §6.2 / §6.3 |
| `layout.ts` | 自動レイアウト（ELK）。人が置いた場所は動かさない | §3.4 |
| `render.ts` | SVG 書き出し | §7 |
| `mermaid.ts` | Mermaid 書き出し。落ちるものは名指しで残す | §7 |

## `experiments/` との違い

- **`src/` は実装。** 仕様に対応し、テスト（`test/`）が適合の確認になる
- **`experiments/` は測定の記録。** S1 の往復ログ・D2 の Git 衝突の実測など、
  「なぜこの設計にしたか」の証拠。書き換えない

実験は `src/` を使う。逆向きに依存させない。
