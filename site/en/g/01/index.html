オンプレのサーバ構成

An on-premise server layout rack by rack, with the redundant power feeds and network links drawn as separate paths

This drawing comes from one YAML file. No shape was moved by hand.

What the source says

構成図の値打ちは、箱ではなく「どこで切れるか」。利用者 → Apache → PHP-FPM → MariaDB と並べると、止まったときにどこまで届くかが読める。

バックアップ先（Wasabi）を同じ箱の中に描くと、本番機ごと失ったときに戻せないことが図から消える。だから保管先は、別の群として離して置く。

昼間は誰も通らない経路でも、DB を触っている。図に出ていない経路は、点検されない。
