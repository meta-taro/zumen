完成デザインではなく UI 構造の正本（UI 方針 §0）。Bottom Navigation は画面ではなく「常にある枠」なので、どのタブでも下に居座る —— そこが Web の画面遷移と違うところ。

左が「いま選んでいるタブ」の画面、右がタブごとの中身。投稿タブだけはモーダルで、タブを切り替えずに上から出る（よくある型）。
