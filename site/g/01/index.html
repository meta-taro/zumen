オンプレのサーバ構成

この図は、下の 1 枚の YAML から描かれています。手で図形を動かしてはいません。

正本に書いてある決まりごと

構成図の値打ちは、箱ではなく「どこで切れるか」。利用者 → Apache → PHP-FPM → MariaDB と並べると、止まったときにどこまで届くかが読める。

バックアップ先（Wasabi）を同じ箱の中に描くと、本番機ごと失ったときに戻せないことが図から消える。だから保管先は、別の群として離して置く。

昼間は誰も通らない経路でも、DB を触っている。図に出ていない経路は、点検されない。夜間バッチは DB のダンプも Wasabi へ書き出す（バックアップの線を描き落とさない）。

mod_php は PHP を Apache の中で動かす方式、PHP-FPM は別プロセスへ FastCGI で渡す方式。両方を書くと、どちらで動いているかが図から読めない。FPM へ渡すのは mod_proxy_fcgi（Apache 2.4 の公式文書が FPM との組み合わせを説明しているhttps://httpd.apache.org/docs/2.4/mod/mod_proxy_fcgi.html 、2026-09-29 取得）。
