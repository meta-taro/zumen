たんぱく質のトポロジー図（TOPS）—— 長さを捨てて、畳み方だけを残す

たんぱく質のトポロジー図（長さを捨てて、畳み方だけを残す）

この図は、下の 1 枚の YAML から描かれています。手で図形を動かしてはいません。

正本に書いてある決まりごと

TOPS 図は、たんぱく質の畳み方を 2 次元に落とした図。ヘリックスは丸、ストランドは三角で描き、二次構造の並び（N 末端から C 末端へ）・シートの上での相対の位置・おおよその向きだけを残す。

線がどこに入るかで、向きが決まる。記号の中心まで引いた線は「上（手前）につながる」、縁で止めた線は「下（奥）」。N 側が縁で C 側が中心なら上向き（三角も上向きに描く）、N 側が中心で C 側が縁なら下向き（三角も下向き）。

長さは描かない。 残基が何個あるか、ループが何残基かは出ない ——だから大きさの違うたんぱく質が、同じ TOPS 図になる。図そのものを鍵にして、畳み方を検索できる。

ロスマンフォールド。 6 本の平行ストランドが、シートの上では321456 の順に並ぶ（左から β3・β2・β1・β4・β5・β6）。β-α-β-α-β の単位が 2 つで、α / β / α の三層サンドイッチ。β3 から β4 へ、シートの反対側へ渡る（crossover）のがこの畳み方の印で、順に並べるだけではこの形にならない。

いちばんよく保たれるのは最初の β-α-β（Gly-x-Gly が急な折り返しを許す）で、そこが FAD・NAD(P) の ADP の燐酸に触れる。

同じ分野の見本

  • 凸レンズ（引く線は 3 本。2 本で像が決まる）
  • サッカーボール（頂点の角は 348°。足りない 12° が球にする）
  • 点字（6 点しかない。「あ」と「1」は同じ形）
  • 勾配（度で書く図面のほうが少ない）
  • 等角図（3 方向を同じ物差しで測れる。円は楕円になる）
  • 巣房（同じ面積を囲むのに、六角は壁がいちばん短い）
  • 作図（目盛りは使わない。同じ開きが等しい長さを作る）
  • 問題図（数を並べる場所ではない。印が意味を運ぶ）
