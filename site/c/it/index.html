IT・ソフトウェア

IT・ソフトウェアの図面 22 枚。すべて YAML 1 枚から描いたもの。

  • オンプレのサーバ構成
  • クラウド構成
  • データの流れ
  • ネットワーク構成
  • テーブルの関係（ER）
  • データセンターのラック配置
  • クラス図（UML）
  • 状態遷移図（UML）
  • ユースケース図（UML）
  • アクティビティ図（UML）
  • ヘッダ（幅がビットの数そのもの。32 で割り切れる）
  • ラック（穴は等間隔ではない。境目が分かるように）
  • PoE（規格に W が 2 つ。差はケーブルで熱になる）
  • 基板（層を増やすのは、GND を近づけるため）
  • 2N（二重にすることではなく、道が一度も交わらないこと）
  • QR コードの作り（先に見つけるものの大きさが、一定）
  • TCP のつなぎ方と切り方（つなぐのは 3 通、切るのは 4 通）
  • LAN ケーブルの結線（A と B の違いは、橙と緑だけ）
  • ハブとスイッチと AP（どこまで届くかが、違いのすべて）
  • 半導体ができるまで（真ん中の 3 つは、層の数だけ繰り返す）
  • データセンターの気流（通路を分けるのは、熱気を吸わせないため）
  • モールス符号（形ではなく、長さの比）
