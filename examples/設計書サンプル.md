# 本番環境の構成

この文書は、**Markdown の本文に構成図を埋める**例です。
下の囲みは `zumen` の正本そのもので、画像ではありません。
`git diff` を見れば、誰が何を直したかが読めます。

```zumen
version: 1
title: 本番構成

# DB は右側に置く。左だと Web からの線が全部交差する。
pins:
  db:
    position: { x: 620, y: 410 }

groups:
  - id: vpc
    label: Production VPC

nodes:
  - id: internet
    type: internet
    label: Internet

  - id: lb
    type: load-balancer
    label: Load Balancer
    group: vpc

  - id: web01
    type: server
    label: Web 01
    group: vpc

  - id: web02
    type: server
    label: Web 02
    group: vpc

  - id: db
    type: database
    label: MariaDB
    group: vpc

edges:
  - from: internet
    to: lb
    protocol: HTTPS

  - from: lb
    to: web01

  - from: lb
    to: web02

  - from: web01
    to: db

  - from: web02
    to: db
```

## この図の直し方

- **文章で頼む**: 「Redis を足して、Web からキャッシュ経路も引いて」
- **手で直す**: 画面で DB を動かすと、`pins` に座標が書かれます。
  次に AI へ頼んでも、その位置は動きません（`spec/zumen-format-v1.md` §6.2）
