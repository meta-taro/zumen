# 見本のネタ帳

**「ニッチだが重要なプロの図面」を、調べて吸収して作れるようにする**
（2026-09-12。オーナーの指示）。

> どんどんニッチだけど重要なプロの図面を検索して吸収して zumen アプリで
> つくれるようにしてほしい

ここは**作る前の置き場**。作ったら「作った」へ移す。
**思い付きを消さない** —— 消すと、なぜそれを狙ったかが失われる（ベースルール §24）。

## 見るところ

新しいネタを足すときは、**その業界の実物を 1 枚は見てから**書く。
実物を見ないと「箱と矢印」になる。これは 2026-09-12 に間取り図で実際にやった
（オーナーの指摘「不動産の間取り図レベル」）。

見るのは 4 点。

1. **符号**は何か（`C1` / `R-A01` / `OP-10`）
2. **寸法**が要るか。要るなら何を基準に測るか（通り芯・壁芯・区画界）
3. **向きのある線**か、**繋がっているだけの線**か（`arrows`）
4. **その図が無いと何ができないか**（拾い出し・積算・申請・点検）

#### ~~課題 7~~ —— 断面・立面（**ほぼ解けた**）

**断面図を 1 枚描いて確かめた**（2026-09-12。擁壁の標準断面図）。
**8 割はそのまま描けた** —— 座標の `y` を高さとして読み替えるだけで、
寸法も通り芯も効く。

違ったのは 3 点で、**2 点は正本の書き方で済んだ。**

| 違い | どうしたか |
|---|---|
| 方位が要らない | **`north` を書かなければ済む**（正本が決める） |
| 貫通・埋設で箱が重なる | **重なりは観測値**で、失敗ではない（元からそう） |
| 横の基準線が通り芯ではなく**レベル** | `mark: level` を足した（三角の高さ記号と値） |

**`kind: section` は足さなかった。** 測り方が配置図と同じで、
`src/kind.ts` に自分で書いた歯止め
（**3 つ目の kind は、測り方が 3 つ目になるときだけ**）に当たった。

残るのは**立面図**（外観）だが、これも測り方は同じはず。
**まだ 1 枚も描いていない**ので、描いてから決める。

#### 課題 8 —— 縦横で縮尺を変える

道路の標準横断図を描いて出てきた（2026-09-12）。

全幅 11.5m と舗装厚 250mm を**同じ縮尺**で描くと、舗装が 13px になって
文字が入らない。**実物は H=1/100・V=1/20 のように縦横で縮尺を変えている。**

縦断図（距離 100m 対 高さ 1m）はもっと極端で、**変えないと図にならない。**

いまは `scale: { mm: 20 }` の 1 つだけ。
`scale: { x: 20, y: 5 }` のように分ければ足りるはずだが、
**寸法の数値が縦横で別の縮尺になる**ので、読み手が取り違えないかを確かめる必要がある
（実物は図面のどこかに「H=1/100 V=1/20」と必ず書いてある）。

**逃げ道はある。** 舗装構成だけを別の図に切り出せば、単一の縮尺で描ける（43 がそれ）。
実物もそうしている（横断図に舗装構成の詳細を吹き出しで付ける）。

#### 課題 7 の残り —— まだ描いていない断面・立面

矩計図・橋梁の一般図・縦断図・擁壁の標準断面図・展開図・立面図。
**「○○図」を業界ごとに数えたら、いちばん多くの図がここで止まっていた。**

平面図は「上から見た配置」で、断面・立面は「横から見た高さ」。
**zumen の `kind` は `structure` / `placement` の 2 つしか無く、どちらも上から見ている。**

要るのは新しい形ではなく、**高さの軸**。
`placement` の座標が (x, y) で平面を指すのに対し、断面では y が高さになる。
`kind: section`（断面）を足せば、**同じ道具立てのまま**描ける可能性がある
—— 通り芯は基準線（GL・FL・天端）に、寸法は高さ寸法になる。

**まず確かめること。** 断面図を 1 枚、いまの `placement` で描いてみる。
`y` を高さとして読み替えるだけで足りるなら、足すのは `kind` の語 1 つで済む。

##### 残り —— シーケンス図

**ライフラインと活性区間**が要る。
縦の時間軸（`mark: tick` を `y` に）は書けるが、
**ライフラインは「縦に伸びる破線」**で、箱でも辺でもない。

いま辺は箱と箱を繋ぐので、**ライフラインの途中に取り付く線**が書けない。
`marker: none` の小さな箱を時刻ごとに並べれば描けるが、
**それは「できる範囲へ図を寄せる」**（オーナーが止めたやり方）。

**メッセージが取り付く先を、箱ではなく「箱と時刻」にできるか**を考えてから作る。

#### 旧 課題 9 の元の記述

UML をひと通り揃えて、**シーケンス図だけが残った**（2026-09-12）。

要るのは形ではなく**軸**。

| 図 | 横軸 | 縦軸 |
|---|---|---|
| シーケンス図 | 相手（ライフライン） | **時刻**（上から下へ） |
| ガントチャート | **時刻**（左から右へ） | 作業 |
| タイムチャート（電子回路） | **時刻** | 信号 |
| 工程表・ネットワーク工程表 | **時刻** | 工程 |

**どれも「時刻の目盛り」と「その上に伸びる帯」で描ける。**
`placement` の座標を時刻として読み替えれば足りるかもしれない
（断面図で `y` を高さとして読み替えたのと同じ筋）。

**まず 1 枚、いまの `placement` でガントチャートを描いて確かめる。**
足りないものが「目盛り」だけなら、`grid` の `mark` に `tick`（時刻の目盛り）を
足すだけで済む可能性がある。

**ガントチャートが描ければ、工程表も同時に開く**（建設・製造でよく使う）。

#### 課題 10 —— 重なり順を正本が決められない

**いまは面積の大きい箱から描く**（`src/render.ts` の `stack`）。
たいていはこれで正しい（広い部屋が下、小さい機器が上）が、**下敷きを敷けない。**

実物の停車駅一覧には、乗換駅の位置に**薄い灰色の縦帯**が帯の後ろを通っている。
細くて背が高いので面積が小さく、**帯より前に出てしまう。**

足すなら `z` のような数ではなく、**「下敷き」という 1 語**にする
（数を許すと正本ごとにばらける。`weight` で数を断ったのと同じ筋）。

#### 課題 11 —— 3 段目の文字（ローマ字）

実物の路線図の駅名は**漢字・ふりがな・ローマ字の 3 段**。
zumen には `label` と `technology` の 2 つしか無いので、**2 段までしか出せない。**

見本 54 はふりがなを採った（実物の右の列と同じ）。
ローマ字は `technology` に書けば寝るが、**両方は出せない。**

#### 課題 12 —— 帯の模様（縞・点線の帯）

阪急の停車駅一覧では、**通勤特急が「橙地に白の破線」**になっている
—— 特急と色が近いので、色だけでは見分けられないため。

`hatch` は帯の色で描くので、**帯と同じ色になって見えない。**
模様の色を別に持てるようにするか、`line` を帯にも効かせるか。

#### 課題 5 —— 自由形状

**万博の大屋根・車の外形・河川の護岸・地形の等高線。**

ノードが矩形しか無い。**これは課題として残すが、優先度は最も低い。**
「配置と寸法が読めること」が図の仕事で、**外形の忠実さはその次**だから。

## やり方 —— 図を描いて、足りないものを見つける

**オーナーの指示（2026-09-12）。**

> また既存の図もブラッシュアップするために機能を追加する調査をする
> という **PDCA** を行ってください。

回し方はこう。

1. **実物を見る**（画像検索・設計基準・標準図集）
2. **同じ図を zumen で描く**
3. **並べて、差が出たところを数える**（絵の好みではなく、**何が読めないか**）
4. **足りない道具を 1 つだけ足す**。足したら、既にある図を全部描き直す
5. **毎回、既にあるものを 1 つ以上ブラッシュアップする**（下記）

### 5 の意味 —— 細かい指摘は、まだ来ていない

**オーナーの指示（2026-09-13）。**

> 最初なので、これまで全体を通して細かいことは言っていません。
> PDCA の時に、なにか少しでも改善を入れるみたいな時に
> **徐々にブラッシュアップ**してくれたらと思っています

いま出ていない指摘は、**無いのではなく、まだ言われていないだけ。**
「言われていない ＝ 直さなくてよい」と読むと、粗いところが既定になって固まる。

**1 周につき、新しい図や道具とは別に、既にあるものを最低 1 つ良くする。**
何を直したかは、その周の報告に 1 行で出す（黙って直すと、良くなったことも伝わらない）。

直す先の探し方（上から順に見る）。

| 見る所 | 何を探すか |
|---|---|
| `inspect` の観測値 | `crossings` / `hiddenLabels` / `crowdedNames` が 0 でないもの |
| 見本を実物と並べる | **今まで「これでいい」と流した所**（線の太さ・間隔・文字の位置） |
| 検証器の警告 | 出ているのに直していないもの |
| 課題の一覧 | 小さく削れるもの（全部は無理でも、1 つ手前まで進める） |
| 文書 | 実装と食い違っている記述（**古い文書は、無い文書より悪い**） |

**「もっと大きな機能」を理由に飛ばさない。** 大きいものは次の周にも残っているが、
細かい粗さは**放置した分だけ実物から遠ざかる。**

この回し方で出てきたもの。

| 描いた図 | 足りなかったもの | 足した道具 |
|---|---|---|
| 間取り | 壁・建具・矢印の有無 | `openings`・平面の描き方 |
| 伏図 | 符号 | `tag` |
| 平面詳細図 | 寸法・基準 | `grid` `scale` `north` |
| 平面詳細図 | 壁の厚み | `wall` |
| 路線図 | 向きの無い線・小さい印の名前 | `arrows: false`・箱の外の文字 |
| 圃場整備 | **細い帯の名前**（用水路・排水路） | **帯に沿って縦に書く** |
| 路線図（作り直し） | **駅が四角くて路線図に見えない** | `marker: circle` / `double`（**`type` は増やさない**） |
| 路線図（日本式） | 線が細く、駅名が駅番号に重なる | `weight: thick`（角丸）／印の中は符号だけ |
| 道路の横断図 | 幅 11.5m と舗装 250mm が同じ縮尺で入らない | **課題 8**（縦横で縮尺を変える） |
| 駅の構内図 | 1 枚に 2 階あると寸法が通しで出る | **課題 3**（1 枚に複数の図）に統合 |
| 舗装構成・弁当 | **「既存でできる範囲」でやっていた**（オーナーの指摘） | `hatch`（材料と区域の模様）・丸に入る短い文字を中へ |
| 総合仮設 | **クレーンの作業半径** | `radius`（範囲の円） |
| 映画館 | **高さ 12px の横通路の名前**が隣へ落ちた | 名前と副題を **1 行に繋いで中へ** |
| 車両編成 | 符号が名前に重なった／上端で文字が画面外へ | 符号の分だけ下げる／出す先の余白を見る |
| 駐車場 | `W1` が縦書きになった（横に入るのに） | **副題だけ横に回す**（名前は中へ） |
| 路線図（色） | **色が路線の名前**なのに、色が無い | `palette` ＋ `color`（**色は正本が持つ**。D24） |
| 路線図（乗換駅） | **駅名の上を路線が走っていた** | 名前の置き場所に**斜め 4 方向**を足し、**線を障害物に数える** |
| 停車駅案内図 | ● が四角く塗られ、名前の無い印に **id が出た** | 塗りを**印の形**に従わせる／`label: ""` は書かない |
| のりかえ案内図（大阪メトロ型） | **駅名が横書きで、駅の間隔に入らない** | `write: down`（**字を積む**。回すのとは別） |
| 停車駅一覧（阪急型） | 線と点では実物に見えない | **帯（`marker: bar`）＋白丸**に作り直した |
| のりかえ案内図 | JR の灰色が**ダークで消えていた** | `color-faint` を**両方の地**で見る |
| 時間割・バス時刻表・登山 | **道具は足りていた**（3 枚とも既存だけで描けた） | 足さない。**足りているのに足すのは、語彙を増やすだけ** |
| 登山のコースタイム図 | **標高の数字を目盛りの線が横切っていた** | 縦の目盛りの線を 1 本にした（長い線が文字の上を通っていた） |
| 商店街・フードコート・ドーム | **道具は足りていた**（3 枚とも既存だけで描けた） | 足さない |
| フードコートの凡例 | **26×20 の見本が、壁厚でほとんど枠になった** | 壁が短辺の 1/5 を超える箱には効かせない（`wallFits`） |

**4 の「1 つだけ」を守る。** まとめて足すと、どれが効いたか分からなくなる。

## ずっと先の話（オーナー）

> カメラでぐるーと写真や動画をとると、その内装図がでる

**いまは作らない。** ただし、**出来上がりが `kind: placement` の正本になる**なら、
この製品の形とは繋がる —— 撮って出した図を**人が直せる**ことが、そのまま
この製品の主張（手直しが再生成で壊れない）になるため。

繋がらないのは、**写真から出た図を人が直したあと、撮り直したらどうするか**。
そこが「再生成」にあたる。**S1 と同じ問題**で、そこが解けていない道具は
「一度きりの変換器」にしかならない。

### まとめ —— 何を足せば、何が開くか

| 足すもの | 開く図 |
|---|---|
| **設備記号**（課題 4） | 消防設備図・衛生器具・コンセント |
| **階層**（課題 1） | 駅の構内図・各階の通し・船の甲板 |
| **曲線**（課題 2） | 道路の線形・河川・砂紋・日影 |
| **断面・立面** | 矩計図・橋梁の一般図・縦断図・擁壁 |
| **三面図／展開図**（課題 3） | 部品図・展開図・什器図 |

**いちばん多くの図が開くのは「断面・立面」。** いまは課題に挙げていなかったので、
**課題 7 として足す。**
