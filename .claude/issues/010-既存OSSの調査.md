# 010 — 既存 OSS・既存手法の調査（作る前に）

- Phase: 0
- 前提: なし
- 優先度: 中

## 目的

**新規実装の前に、既に解かれていないかを調べる。**
特に次の 2 つは、この製品の中核と重なるので必ず見る。

- **人の手直しを保持したまま自動レイアウトする**手法（Issue 001 と同じ問題）
- **テキストから構成図を生成する**既存プロジェクト

## 作業内容

1. 図の記述形式・レイアウトエンジン・生成ツールを横断で調べる
2. それぞれについて次を書く
   - **Issue 001 の問題を解いているか**（解いていれば、それを使う）
   - ライセンス
   - 保守されているか（最終更新・課題の返答）
3. **使えるものは使う。**ゼロから書くのは、使えるものが無かったときだけ

## 完了条件

- 調査した対象の一覧と評価がある
- 「採用する / 採用しない」が理由付きで書かれている
- **採用しない理由が「自分で書きたいから」になっていない**

## 注意

- **調査を省略して実装に入らない。**この製品の中核（手直しの保持）は
  レイアウト分野で長く議論されている問題で、先行例がある可能性が高い
