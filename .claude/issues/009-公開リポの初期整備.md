# 009 — 公開リポの初期整備（個人名検出 CI を初回 commit から）

- Phase: 0（リポ作成直後）
- 前提: なし
- 優先度: 高（**最初の commit の前に読むこと**）

## 目的

このリポは **public** である。**世界中の誰でも読める。**
公開後に気づいて消しても、fork・clone 済みのコピー・履歴に残るため
**完全には消えない。出す前しか対策できない。**

## 作業内容

1. 個人名・個人メールアドレスを検出する CI を入れる（**初回 commit から**）
2. commit の author 情報が個人名・個人メールになっていないか確認する
3. README / ドキュメントの書き方を揃える
   - **役職名ではなく役割で書く**（メンテナ / 利用者 / 貢献者）
   - **他の案件の名前を出さない**
   - **配布先に存在しないファイルへのパスや章番号を書かない**（情報がゼロなのに
     内部文書の存在だけが伝わる）
4. ライセンスと CONTRIBUTING を置く

## 完了条件

- CI が動き、**わざと個人名を入れた commit で落ちること**が確認されている
- 既存の commit 履歴に個人名・個人メールが無いことを確認済み
- README に、この製品が何をするものかが 3 行で書かれている

## 注意

- **CI を入れただけで確認しない。**落ちることを確かめる。落ちない検査は
  「異常なし」を出し続ける
- 説明のために禁止したい語を引用しない（引用した時点でもう一度公開される）

## 作業ログ

### 2026-09-04 — 申し送り（未着手。この Issue で扱うもの）

**`LICENSE` ファイルが無い。** `package.json` は `"license": "MIT"` と宣言しているのに
本文が無い状態。公開前に埋める必要がある。

置くかどうかを人に確認し、**「今は置かない。この Issue でまとめて扱う」**となった。

置くときに決める必要があるのが、**著作権者の表記**。姉妹リポで食い違いがある。

| 出どころ | 値 |
|---|---|
| `md-business/LICENSE` 3 行目 | `Copyright (c) 2026 metataro`（ハイフン無し） |
| GitHub のオーナー（`gh repo view`） | `meta-taro`（ハイフン有り） |

**どちらが意図した表記かは人が決めること。** AI は置かない。
（どちらもハンドルであって個人名ではないので、§25 には触れない）

### 2026-09-04（同日・追記）— `LICENSE` を置いた

人から「**MIT は著作権者表示が必須。だから md-business に meta-taro があって OK**」との指示。
そのとおりで、**著作権者の行が無い MIT は成立しない**（MIT の条件が
「著作権表示と許諾文を全ての複製に含めること」であるため）。

`LICENSE` を設置した。本文は md-business と一字一句同じ、著作権者は
**`Copyright (c) 2026 meta-taro`**（指示された表記。GitHub アカウント名と一致）。

**表記の食い違いは残っている。** md-business 側は `metataro`（ハイフン無し）のまま。
揃えるかどうかは人の判断で、こちらからは触っていない（別リポのため）。

あわせて、依存ライブラリのライセンスは `LICENSES.md` に分けて書いてある
（elkjs が EPL-2.0 OR GPL-3.0。判断の経緯は `decisions.md` の D6）。

### 2026-09-06（同日・追記）— 残りの作業内容を片付けた

**作業内容 3（文書の書き方）**

機械的に点検した。

- **配布先に存在しないファイルへのリンクは 0 件**（全 `.md` のリンクを走査）
- 役職名・他の案件名は無し（`Inc.` の 2 件は商標表記そのもので、案件名ではない）
- README から `.claude/` を参照しているが、**それらはリポジトリに入っている**ので
  「情報がゼロなのに内部文書の存在だけが伝わる」形にはなっていない

**作業内容 4（ライセンスと CONTRIBUTING）**

- `LICENSE` — 済（同日）
- `CONTRIBUTING.md` — 新規。**この製品が守っていること**（`pins` は人だけ／
  AI の出力は提案／黙って上書きしない／人が触っていない行に差分を出さない）を先頭に置いた。
  機能を足す提案は **`pnpm measure` の数字が改善するかで判断する**と書いた
- `SECURITY.md` — 新規。**まだ守れていないことも書いた**
  （AI の API へ繋いでいない／読み込む図を信用している／署名と配布経路が無い）
