# 007 — 出した図が、貼り先で崩れないか

- Phase: 作る順 B2
- 前提: Issue 004
- 優先度: 中

## 目的

構成図は**単体で見るものではなく、資料に貼るもの**である。
出力が資料側で崩れると、人はそこで手作業に戻る（そして図はまた腐る）。

原案 §26 の 7 が同じことを言っている。

## 作業内容

1. 出力を、実際に使われる貼り先で開く（プレゼン資料 / 文書 / Markdown / ブラウザ）
2. 崩れる条件を列挙する（フォント・線・グラデーション・テキストの位置）
3. 崩れないための出力設定を決める

## 完了条件

- 貼り先ごとの結果が書かれている
- 崩れる条件と、その回避方法が書かれている
- **回避できないものは「できない」と書かれている**（できるように読める書き方をしない）
