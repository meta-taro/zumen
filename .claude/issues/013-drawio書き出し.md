# 013 — draw.io XML への書き出し

- Phase: 作る順（急がない）
- 前提: D2 確定済み
- 優先度: 低

## 目的

原案 §29 は draw.io を「将来的な Import/Export 先および UX 参考対象」としている。
D2 では **draw.io XML を正本にしない**と決めたが、**書き出し先としては別の話**である。

Mermaid 書き出しは「翌日**読める**」を担保する。
draw.io 書き出しは「翌日**編集できる**」を担保する。ここが違う。

## 決めること

- 位置・大きさ・線の曲げ方をどこまで写すか（draw.io は全要素が座標を持つので、
  **人の指定と自動配置の区別は写せない**。この情報が落ちることを明記する）
- 圧縮するか（draw.io は既定で deflate+base64 する。**しない**。差分が読めなくなる）

## 作業内容

1. `spec/zumen-format-v1.md` §7 の表に沿って、落ちるものを先に書き出す
2. 書き出しを実装する
3. **実物の draw.io で開いて、図として出ることを人が目で確かめる**

## 完了条件

- 書き出した XML が draw.io で開ける（**実物で確認済み**）
- 落ちるものが文書に書かれている
- `spec/zumen-format-v1.md` §7 の表が更新されている

## 注意

- **落ちるものを黙って落とさない。** Mermaid 書き出しと同じ作法にする
- 書き出しであって、往復（Import）ではない。**取り込みは PRD §4 でやらないと決めている**
