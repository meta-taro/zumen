# 006 — 図形・アイコンのライセンスと配布可否を確認する

- Phase: 作る順 B2 の前
- 前提: なし
- 優先度: 中（**ただし図形を同梱する前に必ず終わらせる**）

## 目的

クラウド構成図で使うアイコン類（各社のサービスアイコン等）は、
**提供元ごとに配布・改変・再配布の条件が違う。**
public な OSS リポに同梱してから気づくと、**公開済みの履歴に残る**（消しても完全には消えない）。

## 作業内容

1. 使う予定のアイコン群について、提供元の利用条件を**一次情報で**確認する
2. 次の 3 つを分けて記録する
   - **同梱してよいか**（リポに置けるか）
   - **改変してよいか**（色・サイズ・簡略化）
   - **表示義務があるか**（帰属表示・商標注記）
3. 同梱できないものは、**利用者が自分で入れる経路**を設計する

## 完了条件

- アイコン群ごとに可否の表がある（出典 URL 付き）
- 同梱するものと、しないものが分かれている
- 同梱しないものの入れ方が README に書ける粒度で書かれている

## 注意

- **「たぶん大丈夫」で同梱しない。**一次情報のない断定を書かない
- **公開リポなので、入れてしまうと後から消しても履歴に残る**
