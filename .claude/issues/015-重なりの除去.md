# 015 — 重なりの除去（人が置いたノードは動かさない）

- Phase: 作る順 B2
- 前提: Issue 010（調査）済み
- 優先度: 中

## 目的

`project-status` の既知問題。

> **重なりの回避は解いていない。** 人が別のノードの真上へ pin を置けば重なる。

図が重なると読めない。読めない図は貼れないので、**そこで人は手作業に戻る。**

## すでに分かっていること（Issue 010 の調査結果）

- 重なりの除去は**解かれている問題**で、手法に名前がある
  （PRISM / **GTree** / Force-Transfer / VPSC）
- **GTree が「元の配置をよく保つ」**ので出発点に向く
  （[Node Overlap Removal by Growing a Tree](https://arxiv.org/pdf/1608.02653)）
- **ただし、そのまま使えるものは無い。** どの手法も**全ノードを動かす**前提で、
  この製品が要るのは「**人が置いたノードは動かさず、機械が置いたノードだけを退ける**」
- **elkjs の `interactive` では解けない。** 実測で重なりが 2 個 → 1 個に減るだけで、
  座標を固定しない（`docs/specs/010-既存OSSの調査.md` §5）

## 決めること

- 退けるのは機械が置いたノードだけか、**囲み（groups）も動かすか**
- どこまで退けるか（**離しすぎると図が広がって読めなくなる**）
- 退けても解けない場合（人が 2 つの pin を重ねて置いた）に何を返すか。
  **黙って動かさない**こと

## 作業内容

1. 重なりを数える形にする（**先に測れるようにする**。`overlaps()` は既にある）
2. 固定ノードを持つ変種として実装する
3. `experiments/` の図と、わざと重ねた図の両方で確かめる

## 完了条件

- **人が別のノードの真上へ pin を置いても、機械が置いたノードが退く**
- **人が置いたノードは 1 px も動かない**（動かしたら、それは手直しを壊したこと）
- 人どうしの pin が重なった場合は、**動かさずに人へ知らせる**
- 退けた結果、図が不必要に広がっていない（広がりを数字で見る）

## 注意

- **重なりが無くなれば良い、ではない。** 人の指定を動かして解いたら、
  この製品の前提（判定基準 3.1）を壊したことになる
- **`pnpm measure` の数字が悪化しないこと。** 退けるために pin を足したら本末転倒

## 作業ログ

- 2026-09-07 実装。`src/separate.ts`。**Force-Transfer に近い素直な押し出し**にした。
  GTree を出発点にする案だったが、**固定ノードを持つ形にすると木を育てる利点が消える**
  （動かせない点が木の中にあると、そこから先へ力を伝えられない）。
  図の規模が数十ノードなので、素直な押し出しで足りる

## 結果

**完了。**

- 実装: `src/separate.ts`。`layout()` の中で、**人の位置を戻した直後・枠を広げる前**に呼ぶ
- `Placed` に `collisions` を足した（**人どうしが重なった組**）
- 画面に「重なったまま」の欄を出す

### やり方

1. 重なっている組を集める（**並びを id で固定**。揺れると差分が読めない）
2. **重なりが浅いほうの軸**へ退ける（深いほうへ退けると図が不必要に広がる）
3. 片方が固定なら**動くほうだけ**が退ける。両方動くなら半分ずつ
4. 重なりが無くなるまで繰り返す（上限 40 回）

### 完了条件との対応

| 完了条件 | 状態 |
|---|---|
| 人が真上へ pin を置いても、機械が置いたノードが退く | 済（テスト） |
| **人が置いたノードは 1 px も動かない** | 済（テスト。座標が完全一致することを見ている） |
| 人どうしの pin が重なったら、**動かさずに知らせる** | 済。`Placed.collisions` と画面の「重なったまま」 |
| 図が不必要に広がっていない | 済（テスト。**桁が変わるほど広がらない**ことを見ている） |

### 注意への対応

- **人の指定を動かして解いていない。** 動かしたら判定基準 3.1 を壊す
- **`pnpm measure` の数字は変わらない**（`separate` は pin を足さない）。`pnpm s3` で確認

### 決めたこと

- **囲み（groups）は動かさない。** 枠は中身に合わせて広がる仕組みが既にある（`fitGroups`）
- **退けるのは隙間 12px まで。** 触れていると読めないが、離しすぎると図が広がる
