# 011 — Git のマージドライバ（形式では解けなかった 2 件）

- Phase: 作る順 B1
- 前提: D2 確定済み
- 優先度: 中

## 目的

D2 の実測（`experiments/d2/results/git-conflict.md`）で、6 場面中 2 場面が
**Git の行単位マージでは解けない**ことが分かった。

| 場面 | 何が起きるか |
|---|---|
| 2 人が別々のノードを動かす | 最初の `pins` を書く場所が両者にとって同じ 1 行なので衝突する |
| 2 人が別々のノードを足す | `nodes` の末尾が両者にとって同じ位置なので衝突する |

**これは YAML の欠点ではない。** Mermaid でも DOT でも draw.io XML でも同じで、
行で管理する以上、同じ場所への同時挿入は必ずぶつかる。

したがって形式を変えても解けない。**解くならマージドライバ**である。

## 決めること（このリポで決めてよい）

- ドライバをどう配るか（`.gitattributes` はリポジトリに置けるが、
  `merge.zumen.driver` の設定は**各利用者の手元で 1 回必要**。これをどう案内するか）
- ドライバが解けない場合に何を返すか（**黙って片方を捨てない**こと）

## 作業内容

1. `merge()` を 3-way に拡張する。いまは 2-way（正本 + 提案）だが、
   Git のドライバは base / ours / theirs の 3 つを受け取る
2. `.gitattributes` に `*.zumen.yaml merge=zumen` を置く
3. `experiments/d2/git-conflict.ts` の 6 場面を、ドライバ有りで回し直す
4. **ドライバを設定していない人が clone した場合に何が起きるか**を確かめる
   （既定のマージへ落ちるだけで、壊れないこと）

## 完了条件

- 6 場面すべてが期待どおりになる（**「衝突するのが正しい」場面は衝突したままであること**）
- ドライバ未設定でも壊れないことを確かめてある
- 設定手順が README に書ける粒度で書かれている

## 注意

- **衝突しなければ良い、ではない。** 本当にぶつかっているのに黙って通すドライバは、
  人の直しを片方だけ消す。D2 の実測表が「衝突するのが正しい」場面を含んでいるのはこのため
- ドライバの設定を**利用の前提にしない**。設定していない人も使えること

### 決めたこと（このリポで決めてよい、とされていた 2 点）

**1. ドライバの配り方**

`.gitattributes` はリポジトリに置く。`merge.zumen.driver` の設定は各自の手元で 1 回。
手順は README に書いた。**設定を利用の前提にしない**ので、
未設定の人は Git の既定へ落ちるだけで壊れない。

**2. 解けない場合に返すもの**

`<<<<<<< ours` / `=======` / `>>>>>>> theirs` の**両方の値を残して**返し、終了コード 1。

- **黙って片方を捨てない。** 捨てると、消えたことが誰にも見えない
- 印を Git と同じ形にしたのは、エディタの競合表示や
  `git checkout --ours` といった**使い慣れた道具を効かせる**ため
- 囲むのはぶつかった要素だけで、前後の行は巻き込まない

### 完了条件との対応

| 完了条件 | 状態 |
|---|---|
| 6 場面すべてが期待どおり（**衝突するのが正しい場面は衝突したまま**であること） | 済。**ドライバ有り 6/6。**「2 人が同じノードを別の場所へ動かす」は衝突したまま |
| ドライバ未設定でも壊れないことを確かめてある | 済。実測表の「既定」列（従来どおり 6 中 4。**壊れてはいない**） |
| 設定手順が README に書ける粒度 | 済。README に記載済み |

### 注意への対応

- **黙って通していない。** 同じ要素を別々に変えた場面は、ドライバ有りでも衝突する。
  テストでも「両方の値が印の中に残る」「隣の行を巻き込まない」を押さえた
- **設定を前提にしていない。** 未設定でも壊れないことを実測で確認

### 残していること

- **3 人以上の同時変更は見ていない**（Git のマージは常に 2 者なので、当面は不要）
- **YAML として読めない状態でぶつかった場合**は、構造マージを諦めて 1 を返す。
  そこで勝手に片方を書くと、人の直しが黙って消える
- `pins` 以外の入れ子（将来 `groups` が入れ子になったとき）は見ていない
