# 周の回し方 —— **時間で区切る**

> **オーナーの指示（2026-09-21）。**
>
> > 時間で見てもらうのが手堅いです。**何時くらいまで自動で進めといて**みたいな。
>
> **周の数ではなく、終わりの時刻を渡してもらう。**

---

## 0. なぜ時刻か

周の数で渡すと、1 周の重さが揃わないので読めない。
**比（見本 1 : 手入れ N）を機械に守らせる案は、やりすぎだと言われて捨てた**
——「そんなに問題にならない」。

**時刻は誤魔化せない。** 数えるのは終わってからでよい。

---

## 1. 渡され方

> 「**深夜 3 時まで自動で進めておいて**」

これだけ。周の数も、何を描くかも指定されない前提で組む。

## 2. 始めるときに 1 回だけやること

```bash
date                                    # 終わりの時刻まで何時間あるか
pnpm laps --fields                      # いまの比の目安と、薄い分野
git log --oneline origin/develop..HEAD | wc -l   # 未 push が何件あるか
```

**未 push が積んである前提で動く。** 人が push しない間は **CI が 1 度も走らない**ので、
**`pnpm test` が唯一の門**になる。落ちたまま次へ進まない。

## 3. 1 周の中身（これまでどおり）

| | |
|---|---|
| 主 | レパートリーを増やす（`専門図面の調査と実装方針.md` の順序で）|
| 主 | ブラッシュアップを 1 つ以上 |
| 主 | 描いた図を 1 枚は実物で見る |

**終わったら `.claude/laps.tsv` に 1 行足して commit。** 台帳は門番ではなく、
**戻ってきた人へ 300 commit を 1 枚にして渡すための材料。**

## 4. 見本と手入れのウェイト

**2026-09-21 に測って 1 : 3 にした。** 根拠は限界効用 ——

> **見本 322 を最後に、新しい見本から検査が 1 つも出ていない**（そこまでは 5〜8 枚に 1 つ）。
> 直近 20 枚で出た検査は 0。`--tally` も 342 枚中 333 枚が無警告。

**固定しない。** `pnpm laps` が直近 20 周の収穫から目安を出し直す。

| 直近 20 周の収穫（検査・決まり・道具）| 目安 |
|---|---|
| 3 件以上 | 見本 1 : 手入れ 1 |
| 1〜2 件 | 1 : 2 |
| **0 件** | **1 : 3。しかも薄い分野か、まだ当たっていない図法だけ** |

**薄い分野は `pnpm laps --fields` が出す。** 濃い分野で「もう 1 枚描けるから描く」のはやめる。

## 5. 途中で必ずやること

| いつ | 何を |
|---|---|
| 毎周 | `pnpm test`（対象を絞ってよい）／ `bash .github/scripts/oss-privacy-check.sh` |
| 毎周 | **`pnpm gallery` の出力は `grep` で絞らない**（`tail -3` で受ける）。絞ると、自分で足した警告を自分で消す |
| **5 周ごと** | **`pnpm test` を全部**。CI が走らないので、ここが唯一の門 |
| 20 周ごと | `pnpm laps` で比を見直す |

## 6. 止める条件

**時刻まで回すが、下の 3 つが出たら、そこで止めて記録する。**

1. **`pnpm test` が落ちて、自分の変更が原因ではない**（環境・依存）
2. **人にしかできないものに当たった** —— 秘密情報、push、PR を通す、実物を見ての合否、見た目の決定
3. **同じ直しが 3 周続けて空振り** —— 測っても何も出ない状態が続くなら、題材ではなく**渡す相手が間違っている**

止めたときは `.claude/laps.tsv` に `block` で 1 行残す。**黙って別の作業へ移らない。**

## 7. 終わったら渡すもの

```bash
pnpm laps --digest
```

- 何周回して、見本を何枚足して、何が出たか
- **人待ちで止めたもの**
- 未 push の件数と、`! git push origin develop` の 1 行

**300 commit をそのまま読ませない。** 読む場所を 1 つにする。

---

## 8. やらないこと

- **push しない**（ベースルール §6）。時間で回していても変わらない
- **`develop → main` の PR を勝手に作らない。** 通すのは人で、通った時点で公開される
- **落ちるテストを消さない。** CI が走らない間は、消したことに誰も気づけない
- **人待ちのものを、待っている間に「代わりに決めて」進めない**
