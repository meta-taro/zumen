# アイコン

**中身はここではなく `app/icon.svg` にあります。** ここに並ぶ PNG / ICNS / ICO は、
そこから作った出力です。**直接いじらないでください**（次の生成で消えます）。

```bash
pnpm icon
```

`app/icon.svg` → 1024×1024 の PNG → 各プラットフォームぶん、の順に作り直します。
Chrome が要ります（無ければ、その旨を言って止まります）。

`tauri.conf.json` の `bundle.icon` は、ここに出る 5 つを指しています。

## 配色

**人が決めたもの**（2026-09-07）。**AI が埋めた既定値ではありません**（ベースルール §11）。

| | |
|---|---|
| 地 | `#23232b`（ダークグレー） |
| 主役の 1 つ | `#a32b48`（ワインレッド） |
| ほかの箱と線 | `#d8d8e0` |

理由は `DESIGN.md` §6。

## iOS / Android は置きません

この製品はデスクトップだけです（D1 / PRD §4）。
`pnpm icon` が生成しても、その場で消します。**要らないものを置いたままにしない。**
