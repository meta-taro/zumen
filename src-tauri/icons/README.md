# アイコン

**いまのものは仮です。**

`icon.png` は `--accent`（`#5b5bd6`）で塗っただけの正方形で、
中身を作り込んでいません。**見た目の方向性は人が決める領域**であり、
AI が埋めた既定値はそのまま既成事実になるためです（ベースルール §11）。

差し替えるときは 1024×1024 の PNG を用意して、

```bash
pnpm exec tauri icon <用意した.png>
```

を走らせると、各プラットフォームぶんがこの階層に生成されます。
生成されたら `tauri.conf.json` の `bundle.icon` をその一覧へ広げてください。
