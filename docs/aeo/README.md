# 見つけてもらう —— AEO / GEO の PDCA

AI に「こういう図を描ける道具は？」と聞かれたとき、**製品名を知らない人の問いから zumen に辿り着けるか**を測り、直し、測り直す。

検索順位を上げる話ではない。**AI と検索エンジンが zumen を何と説明するか**を、こちらが書いた言葉で決めておく話。

## 1 周

| 段 | やること | 置き場所 |
|---|---|---|
| **P 測る** | 製品名を伏せた問い 25 本（日英）で検索し、zumen が出るか・どの競合がどんな言い方で出るかを記録する | `baseline-<日付>.md`（初回）／ `run-<日付>.md`（2 回目から） |
| **D 直す** | 足りない語を、名乗りの置き場所へ入れる（下の表） | 各ファイル |
| **C 測り直す** | **日を置いて**（反映に日がかかる。目安 2 週）、**同じ 25 本**で測る。問いを変えると比べられない | `run-<日付>.md` |
| **A 決める** | 差を見て、次に直す所を 1 つ決め、この表の下に 1 行残す | このファイルの「記録」 |

**問いは変えない。** 変えるなら、変えた周を「新しい基準線」として始め直す。

## 名乗りの置き場所（どれも同じことを、同じ語で言う）

| 置き場所 | 読む人 | 機械で見ているか |
|---|---|---|
| npm の `description` ／ `keywords`（`package.json`） | npm の検索・AI | `test/discoverability.test.ts` |
| GitHub の About（説明・topics・homepage） | GitHub の検索・AI | 人（`gh repo edit` は人が打つ） |
| README の冒頭（日英） | 人・AI | `test/readme-links.test.ts`（リンク）|
| 紹介ページの `<title>` ／ `description` ／ JSON-LD | 検索エンジン | `test/discoverability.test.ts` |
| `site/llms.txt` | AI | `test/discoverability.test.ts` |

**語は盛らない。** できないことを書かない（Web 版・共同編集は作らない。PRD §4）。
比べる相手の名前（draw.io・Mermaid）を出すのは、**書き出せる・置き換えられる事実がある所だけ**。
