2. **日本語で出たのは、紹介記事 1 本の力。** 記事は効く。Zenn は検索に強い
3. **「MCP で作図」の席は draw.io と Excalidraw が取っている。** 公式の MCP 頁・GitHub の README・比較記事（nimbalyst・heyclau.de・dev.to）の 3 層で出ている
4. **比較・まとめの記事が入口になっている**（nimbalyst「Best AI Diagram Tools for Engineers and Claude Code」が 4 本に出た）。そこに載ると、複数の問いでまとめて出る
5. **専門図面の問いでは、競合はその分野の専用ソフト**（StackBuilder・drafty・Vectorworks）。「AI で」「テキストで」の席は空いている
6. 問い 11・21 は言葉が検索に通じない（11 は専門すぎ、21 は「AI イラスト」に取られる）。**問いを変えると比べられなくなるので、2 周目もこのまま使い、結果の読みで外す**
