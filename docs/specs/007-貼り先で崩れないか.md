# 出した図が、貼り先で崩れないか（Issue 007）

- 出力: `pnpm svg <図>` / `pnpm drawio <図>` / `pnpm mermaid <図>` / `pnpm embed <Markdown>`
- 見張り: `test/paste-safety.test.ts`（**後から危ない機能が入り込むのを止める**）
- **貼り先での確認は人の作業。** §4 の検証シートは空欄のまま置いてある

---

## 0. なぜ気にするか

構成図は**単体で見るものではなく、資料に貼るもの**。
出力が資料側で崩れると、人はそこで手作業に戻る。**そして図はまた腐る。**

---

## 1. 機械的に直したもの（2026-09-06）

出力そのものを調べて見つかった問題。**貼り先で開く前に分かるものは、先に潰した。**

| 見つかったもの | 何が起きるか | どうしたか |
|---|---|---|
| **`font-family` が 1 つも無かった** | 書体を貼り先の既定に委ねることになる。**日本語のラベルが豆腐（□）になり得る** | すべての文字に `font-family` を付けた |
| `orient="auto-start-reverse"` | **SVG 2 の値。** 古い解釈系では矢印の向きが決まらない | `orient="auto"` に変えた。`marker-end` しか使わないので等価 |
| 寸法が `width="490.66666666666663"` | 貼り先へ渡す寸法が不安定。**Markdown 埋め込みの data URI も膨らむ** | 座標は四捨五入、全体の寸法は**切り上げ**（丸めて縮めると端が 1 px 欠ける） |

### 書体について

**総称ファミリ（`sans-serif`）だけを書いている。**
具体的な書体名は書かない。**見た目は人が決める領域**だから（ベースルール §11）。

`DESIGN.md` が決まったら、そこの書体へ差し替える。
差し替え先は `src/render.ts` の `FONT` の 1 か所。

---

## 2. 意図的に使っていない機能

**使える機能を全部使わない**という方針。貼り先ごとに解釈が割れるものは避ける。

| 使わないもの | 理由 |
|---|---|
| `<style>` | CSS の解釈が貼り先ごとに違う |
| `foreignObject` | 対応していない貼り先が多い |
| グラデーション・フィルタ | 落ちる貼り先がある |
| **`dominant-baseline`** | 効かない貼り先があり、**効かないと文字だけがずれる**。縦位置は座標で決める |
| `xlink:` | 古い名前空間 |
| `<image>` | 外部の絵に依存しない |

**この一覧は `test/paste-safety.test.ts` が守っている。**
文書に書くだけだと、半年後に誰かが `<style>` を足して終わる。

必ず書くものも決めてある。`width` / `height` と `viewBox` の**両方**、
`xmlns`、すべての文字に `font-family`。

---

## 3. 原理的に避けられないもの（**できないと書く**）

### 3.1 書体の実物は貼り先が決める

SVG に書けるのは**書体の名前**であって、書体そのものではない。
`sans-serif` がどの書体になるかは、開いた機械が決める。

**結果として、同じ図でも機械によって文字の幅が変わる。**
幅が変われば、**長いラベルは箱からはみ出す。**

回避する方法は 2 つあるが、どちらも代償が大きい。

| 方法 | 代償 |
|---|---|
| 書体をファイルへ埋め込む | ファイルが数百 KB〜数 MB になる。**書体のライセンスの問題も出る**（D7 と同種） |
| 文字を図形（path）に変換する | **文字が選べない・検索できない・翻訳できない。** 差分も読めなくなる |

**いまはどちらも採っていない。** どちらを採るかは、
実際にはみ出しが起きてから、人が決めること。

### 3.2 貼り先が SVG を受け付けない場合

受け付けない貼り先には、**SVG 側では何もできない。**
必要なら PNG 化が要るが、**zumen は現時点でラスタライザを持っていない**
（依存を増やすので、要ると分かってから入れる）。

### 3.3 図が大きいと縮小される

貼り先の版面より大きい図は縮小される。**文字が読めなくなる。**
これは出力の問題ではなく、図の大きさの問題。
