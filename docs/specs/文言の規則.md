# 文言の規則 — 利用者に見える日本語

- 対象: `src/messages.ts` に入るすべての文字列（画面・CLI・書き出しに現れるもの）
- **この文書は人が直してよい。** ここに書いてあるのは、
  **このリポジトリの既存の文章から観察した用法**であって、AI が発明した文体ではない
- 実装側の約束は `src/messages.ts` の冒頭。**散らばりは `test/messages.test.ts` が落とす**

---

## 0. なぜ規則が要るか

AI に書かせた日本語は、意味は合っているのに読むと引っかかる。原因はだいたい 3 つで、
どれも「自然な日本語で書く」という指示では直らない。

1. **語彙が揺れる。** 同じものを 3 通りの言い方で呼ぶ
2. **翻訳調になる。** 「無効な値です」「操作は完了しました」のような、
   英語の型をそのまま日本語にした文
3. **何が起きたか書いていない。** 「エラーが発生しました」は、
   起きたことを一切伝えていないのに、伝えた気になれる

以下は、この 3 つを潰すためだけの規則。**美文の規則ではない。**

---

## 1. 語彙 — この製品の言葉

**左を使う。右を使わない。**（右が悪いのではなく、混ざるのが悪い）

| 使う | 使わない | 何を指すか |
|---|---|---|
| **正本** | 元ファイル / ソース / マスタ | 人が持っている `.zumen.yaml`。**書き換わるのは常にこちら** |
| **提案** | AI の出力 / 生成結果 | AI が返したもの。**正本ではない**（D5） |
| **手直し** | 編集 / 修正 / カスタマイズ | 人が図に手で入れた指定（`pins`） |
| **往復** | ラウンドトリップ / イテレーション | 人が直し、AI がまた書く、その 1 巡 |
| **囲み** | フェンス / コードブロック | Markdown の ```` ```zumen ```` |
| **競合** | コンフリクト | 人の指定と AI の提案が食い違っている状態 |
| **体裁** | スタイル / 見た目 | 色や線種。**意味の語で書く**（仕様 §4） |
| **書き出し** | エクスポート / 出力 | Mermaid や draw.io へ変換すること |
| **人／書いた人／利用者** | ユーザー | 図を書く人。**画面に出す文では「ユーザー」を使わない** |

新しい語を足すときは、**この表に足してから使う。**

---

## 2. 文の作り方

### 起きたことを書く。判定だけを書かない

- ✗ `エラーが発生しました`
- ✗ `無効な値です`
- ○ `4 行目: インデントが揃っていません`

**人が次に何をすればよいかが分かる情報を入れる。**
どこで（行番号・要素の id）、何が（起きた事実）。

### 責めない。原因を物に向ける

- ✗ `不正な入力です`
- ✗ `指定が間違っています`
- ○ `id "db" がどのノードも指していません`

### 翻訳調を避ける

| ✗ | ○ |
|---|---|
| 〜することができます | 〜できます |
| 〜を行う | 〜する |
| 操作は完了しました | 保存しました |
| 〜してください（毎回） | 事実を書く。**指示は本当に指示のときだけ** |

### 体言止めと敬体を混ぜない

1 つの文言表の中では**敬体（です・ます）で揃える**。
見出し・ラベルのような短い語は体言止めでよい。

### 「の」を 3 つ続けない

- ✗ `図の要素の位置の指定`
- ○ `要素の位置を指定したもの`

---

## 3. 長さ

- **1 行に収める。** 収まらないなら、事実の行と補足の行に分ける
- 画面の 1 行は全角 40 字を目安にする。**超えたら削る。折り返しで逃げない**

---

## 4. 英語（`en`）について

- **`ja` が正本、`en` が追随。** 日本語を先に決めてから英語を書く
- 直訳しない。**同じことを英語で言い直す**
- 語彙表の対応は `src/messages.ts` の `en` を見れば足りる程度に保つ

---

## 5. 人がやること

- **文言を直すのは人の仕事。** `src/messages.ts` の `ja` を直接書き換えてよい。
  テストは文面に依存していないので、**書き換えてもテストは落ちない**
- 違和感を見つけたら、直したうえで**この文書の規則を 1 行足す**。
  直しただけだと、次に同じ違和感が戻ってくる
